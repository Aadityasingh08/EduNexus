> **"One intelligent ecosystem for smarter learning."**  
> EduNexus unifies courses, syllabus tracking, interactive quizzes, diagnostic misconception analysis, knowledge mapping, personalized study scheduling, career guidance, and AI tutoring into a single, breathtaking platform.

---

## ✨ Why Choose EduNexus?

Learning shouldn’t just be about memorization; it should be about **mastery**.  
EduNexus transforms standard study materials into an interactive, AI-driven experience. From generating on-the-fly Socratic diagnostic quizzes to plotting your cognitive progress on a mastery map, EduNexus is the **ultimate digital study companion**.

---

## ⚡ Quick Start

### 🌐 Live Demo
The project is currently deployed and fully live. **Experience it yourself:**
👉 **[EduNexus Live App](https://edunexus-blush.vercel.app)**  
*(Backend & Frontend both integrated natively via Serverless Functions)*

### 💻 Local Setup (Windows / macOS / Linux)

Run this directly in your terminal to spin up the entire ecosystem on your local machine:
```bash
npm install
npm run dev
```
*(Runs Vite with HMR and launches your browser automatically)*

## 🧭 Platform Features Matrix

| Feature | Description |
| :--- | :--- |
| **🧠 AI Tutor (`/tutor`)** | 3-pane experience with Socratic breakdown, analogies, code snippets, and contextual metadata. |
| **🕸️ Knowledge Map (`/knowledge-map`)** | Pan/zoom SVG graph with node mastery statuses (🟢 Mastered, 🔵 Learning, 🟠 Needs Practice, 🔴 Weak). |
| **📝 Diagnostic Quizzes (`/quizzes`)** | AI Quiz Generator, active runner, and deep misconception analysis. |
| **🗓️ Smart Study Planner (`/study-plan`)** | Adaptive timeline with automated workload rescheduling suggestions. |
| **⏱️ Deep Focus Mode** | Distraction-free Pomodoro timer with ambient sounds and session checklist. |
| **📈 Analytics & Trends (`/progress`)** | Retention graphs, study time breakdown, and cognitive behavioral insights. |
| **🚀 Career Pathways (`/career`)** | Industry benchmarks, readiness scores, and project roadmaps. |
| **🤝 Student Community (`/community`)** | Peer discussions, upvotes, and Q&A. |

---

## 🛠️ Tech Stack Architecture

- **Frontend Framework**: React 19 + TypeScript + Vite
- **Backend Infrastructure**: Express.js (Deployed on Vercel Serverless Functions)
- **Styling Engine**: Tailwind CSS + Plus Jakarta Sans Typography + Custom Design Tokens
- **Icons & Graphics**: Lucide React
- **Data Visualizations**: Recharts
- **State & Sync**: Persistent Zustand store linked with LocalStorage
- **Animations & Effects**: Canvas Confetti & Modern Glassmorphism
